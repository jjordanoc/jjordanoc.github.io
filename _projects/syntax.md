**Role:** Co-Founder & CTO — Syntax AI, Lima, Peru (Feb 2023 – Jun 2024)

- Built the product MVP and investor demos used during a \$125k pre-seed raise, scaling Syntax to **5,000+ users**; taught live English sessions with users, uncovering learning gaps and translating them into repeated-practice features.
- Developed long-term conversational memory and multi-agent personalization with 9 LLM agents for memory extraction, summarization, and routing, using OpenAI embeddings and Supabase vector search to retrieve memories.
- Engineered a speech-to-speech pipeline with streaming Azure transcription, LLM dialogue, and AWS TTS, plus asynchronous Whisper and LLM pipelines for pronunciation, grammar, and vocabulary feedback across **50+ hours** of student audio per month.
- Automated CI/CD and mobile E2E testing with GitHub Actions, pytest, and Patrol across core user flows, replacing manual release testing and supporting weekly production releases.
